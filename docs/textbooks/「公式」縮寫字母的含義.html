「公式」縮寫字母的含義

Steam Table / Psychrometric Chart / Moist Air / Dry Air / Water Vapor

研究組員：李世權 Gemini，美工排版：Copilot

目錄

1. 水蒸汽性質表（Steam Table）的代號理解

這裡幫你把這三個區域與三條線對照得更結構化：

  • 飽和液線（Saturated Liquid Line）及以下： 使用 $f$（fluid）或 $l$（liquid）。$w$（water）在某些特殊圖表（如歐美舊制）也會看到。這代表完全是液態水的狀態。
  • 液-氣飽和區（濕蒸汽區 / 未飽和汽區）： 使用 $fg$。它代表「從液態（$f$）轉變到氣態（$g$）的變化量或共存狀態」（例如 $h_{fg} = h_g - h_f$）。此區的未飽和蒸汽就是由 $f$ 與 $g$ 混合而成。
  • 飽和氣線（Saturated Vapor Line）及以上（過熱區）： 使用 $g$（gas / vapor）。代表水已經完全氣化。
  • 名詞稱呼： Steam 就是「水蒸氣」的專屬統稱。
重點： 在 Steam Table 中，$f$ 表示液態，$fg$ 表示液氣共存的相變化，$g$ 表示完全氣態，三者連成完整相變路徑。

2. 空氣性質圖（Psychrometric Chart）的代號理解

符合國際工程界（如 ASHRAE）的標準定義：

  • 乾空氣： 用 $da$（dry air）或大氣計算中的 $a$。
  • 水分： 用 $v$（vapor）或 $w$（water / water vapor）。在未飽和的空氣中，水分是以完全氣態的狀態存在，所以公式寫 $m_v$ 或 $P_v$。
  • 飽和水蒸氣： 用 $w_s$ 或 $v_s$（下標 $s$ 即代表 Saturated）。當空氣達到飽和比濕時，代號就會寫成 $W_s$。
名詞說明
  • Air： 在圖表和空調工程中，單純講 Air 通常就是指「濕空氣（Moist air）」，也就是「乾空氣 + 水分」的混合體。
  • Vapor： 指型態上完全是氣體的狀態。
  • Water： 指濕空氣中含有的水分。

結論
最重要的脈絡是：Steam Table 以水本身的相態為主，Psychrometric Chart 以濕空氣的混合體為主。前者的 $f, fg, g$ 描述的是「水的相變」；後者的 $da, v, W_s$ 描述的是「空氣中乾氣與水汽的混合比例」。

四大常用家庭燈具改裝 SOP

專案 1

客廳 / 主臥：舊燈升級為 LED 快拆吸頂燈

推薦產品：Panasonic 松下 5.5W~50W 雙色無極調光 LED 吸頂燈
或主臥 30W LED 快拆吸頂燈（約 3200–3800 lm）
  • 切斷該迴路 NFB（無熔絲斷路器）後，務必以三步驟驗電法確認完全無電（NFB 跳開只是第一步，配電盤標示不清、迴路交叉或斷路器故障都可能誤判，若不確定迴路對應關係，建議直接切總開關施工）。
  • 拆除舊燈具，拉出天花板預留火線與零線，並靜置約 10–30 秒讓驅動器內部電容自然放電。
  • 安裝引掛底座，將燈體扣上並重新上電測試。
適用空間 客廳 / 主臥
專案 2

房間 / 書房：高品質護眼 LED 球泡燈

推薦產品：飛利浦 EyeComfort 護眼高演色 LED 球泡燈
E27 接口 / 10W–13W / 1000–1500 lm / Ra > 90
  • 確認燈具螺口為標準 E27，並檢查最大耐受瓦數。
  • 關閉開關待冷卻後，逆時針旋出舊燈泡，換上新燈泡。
  • 以書桌或讀書區照度計測試，確保桌面達 500 Lux 以上。
適用空間 書房 / 兒童房
專案 3

走道 / 床邊：防跌感應夜燈加裝

推薦產品：米家人體感應夜燈 2 或飛利浦 LED 磁吸感應夜燈
暖光 3000K，柔光不刺激眼睛
  • 選擇離地約 30 cm 的牆角或床邊下緣安裝。
  • 用 75% 酒精擦淨牆面後貼附底座並按壓 30 秒。
  • 走過測試感應靈敏度與自動熄滅時間。
適用空間 走廊 / 夜燈
專案 4

廚房切菜區 / 書桌：手掃感應 LED 硬燈條

推薦產品：Yeelight 或飛利浦廚櫃手掃感應超薄 LED 硬燈條套組
鋁合金散熱、自然光 4000K、免改電線直插式適配器
  • 量測吊櫃或層板長度，挑選適合尺寸燈條。
  • 用酒精擦淨貼附面後將燈條平整黏貼固定。
  • 整理線材，接上電源後測試感應與無段調光。
適用空間 廚房 / 書桌

常見疑難雜症 FAQ

Q：換了新 LED 燈泡後，明明關掉開關，燈泡卻還會發微光（鬼火／殘光現象）？
原因解析： 若家中開關是帶指示燈的夜光單切開關，關閉時仍可能有微弱電流透過指示燈迴路洩漏，經過 LED 驅動電路後在燈珠上呈現微亮。
  • 方案 A（優先推薦，新手最安全）： 將牆面開關面板更換為「無指示燈」的普通開關，從源頭切斷漏電路徑，且施工僅涉及開關本身，風險較低。
  • 方案 B（進階，需電匠協助）： 於燈具電源輸入端（火線與零線之間）並聯一顆額定電壓 ≥400V 的抑制／消荷電容（俗稱「LED 消除殘光電容」，容值常見 0.1–0.47μF，電料行可洽詢），以吸收洩漏電流。此做法需拆開燈具、直接處理火線與零線接點，務必先確實斷電並完成驗電確認，若不熟悉配線，建議委由持有技術士證照之電匠施作，不建議新手自行嘗試。
提醒：市售抑制電容多為電料行通路的一般規格零件，並非特定電器大廠的專屬型號商品；選購時請確認電容「額定電壓」與「容值」是否適合家用 110V/220V 迴路，並優先向實體電料行或有信譽的賣家洽詢，避免購買來源不明、無耐壓標示的產品。
Q：我該如何選擇色溫，不會買錯？
一般建議：臥室與休息空間選 3000K 暖白；客廳、書房、廚房選 4000K 自然光；需要高專注作業時可考慮 6500K 晝光。 關鍵是「功能空間」與「使用時段」一起考慮，而不是單看燈泡牌價。
Q：為什麼有些 LED 燈具會頻閃？
常見原因包括驅動電源品質差、低價無名品牌、開關調光器相容性不佳、以及安裝環境發熱過高。選購時優先選擇有認證、演色指數較高、無可視頻閃的產品。

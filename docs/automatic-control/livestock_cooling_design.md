# 農舍濕簾排風扇系統蒸發性冷卻設計計算書

## 1. 設計基準及依據來源

### 1.1 畜舍室內環境設計基準

#### 1.1.1 雞舍環境基準
- **設計溫度**：25°C ± 2°C
- **相對濕度**：60% ± 10%
- **最小外氣量**：0.5 m³/min/隻（蛋雞）
- **冷卻通風量**：8-12 m³/min/隻（夏季）
- **照度**：10-20 lux（產蛋期）

*依據：中華民國畜牧場設施設計規範、ASABE Standards EP270.5*

#### 1.1.2 鴨舍環境基準
- **設計溫度**：22°C ± 2°C
- **相對濕度**：65% ± 10%
- **最小外氣量**：0.8 m³/min/隻
- **冷卻通風量**：10-15 m³/min/隻（夏季）
- **照度**：5-15 lux

*依據：農業部畜牧場設施設計指引*

#### 1.1.3 豬舍環境基準
- **設計溫度**：18-22°C（成豬）
- **相對濕度**：60-70%
- **最小外氣量**：20 m³/h/100kg體重
- **冷卻通風量**：200-300 m³/h/100kg體重
- **照度**：40-200 lux

*依據：CNS 3055 豬舍設計規範、ASABE Standards EP270.5*

#### 1.1.4 牛舍環境基準
- **設計溫度**：16-24°C（泌乳牛）
- **相對濕度**：50-70%
- **最小外氣量**：150 m³/h/頭
- **冷卻通風量**：500-800 m³/h/頭
- **照度**：150-200 lux

*依據：美國農業工程師學會ASAE Standards、乳牛舍設計規範*

### 1.2 外氣設計條件
- **夏季外氣乾球溫度**：35°C
- **夏季外氣相對濕度**：75%
- **外氣濕球溫度**：31.3°C
- **設計地點**：台灣中部地區

*依據：中央氣象局氣象統計資料、ASHRAE Climate Data*

## 2. 室內空氣調節冷卻負荷計算

### 2.1 畜舍冷卻負荷計算式

#### 2.1.1 牲畜顯熱負荷
**雞舍顯熱負荷（成雞）：**
```
Qs = N × qs × CF
```
其中：
- Qs = 顯熱負荷 (W)
- N = 雞隻數量 (隻)
- qs = 單隻顯熱散發量 = 8.5 W/隻（2kg成雞，25°C）
- CF = 修正係數 = 1.0

#### 2.1.2 牲畜潛熱負荷
**雞舍潛熱負荷：**
```
Ql = N × ql × CF
```
其中：
- Ql = 潛熱負荷 (W)
- ql = 單隻潛熱散發量 = 6.5 W/隻（2kg成雞，25°C）

#### 2.1.3 照明負荷
```
Qlight = P × A × η
```
其中：
- P = 照明密度 = 3 W/m²
- A = 畜舍面積 (m²)
- η = 照明效率 = 0.85

#### 2.1.4 機具負荷
```
Qequip = Σ(Pi × ηi × CFi)
```
其中：
- Pi = 各機具功率 (W)
- ηi = 各機具效率
- CFi = 各機具同時使用率

### 2.2 建築物傳熱負荷

#### 2.2.1 外牆傳熱負荷
```
Qwall = U × A × ΔT × CLTD
```
其中：
- U = 外牆熱傳係數 = 0.8 W/m²·K
- A = 外牆面積 (m²)
- ΔT = 室內外溫差 (K)
- CLTD = 冷卻負荷溫差 = 8°C

#### 2.2.2 屋頂傳熱負荷
```
Qroof = U × A × ΔT × CLTD
```
其中：
- U = 屋頂熱傳係數 = 0.5 W/m²·K
- CLTD = 冷卻負荷溫差 = 15°C

#### 2.2.3 日射負荷
```
Qsolar = A × I × SC × SCL
```
其中：
- I = 日射強度 = 800 W/m²
- SC = 遮陽係數 = 0.6
- SCL = 日射冷卻負荷係數 = 0.8

### 2.3 總冷卻負荷
```
Qtotal = Qs + Ql + Qlight + Qequip + Qwall + Qroof + Qsolar
```

## 3. 水簾百葉設計計算

### 3.1 水簾百葉設計參數

#### 3.1.1 外氣設計進風條件
- **乾球溫度**：35°C
- **相對濕度**：75%
- **濕球溫度**：31.3°C
- **比焓**：h₁ = 104.5 kJ/kg

#### 3.1.2 水簾百葉離風條件計算
**蒸發冷卻效率：**
```
η = (T₁ - T₂) / (T₁ - Twb₁)
```
其中：
- η = 蒸發冷卻效率 = 0.85（波紋紙水簾）
- T₁ = 外氣乾球溫度 = 35°C
- T₂ = 水簾出口溫度 (°C)
- Twb₁ = 外氣濕球溫度 = 31.3°C

**水簾出口溫度：**
```
T₂ = T₁ - η × (T₁ - Twb₁)
T₂ = 35 - 0.85 × (35 - 31.3) = 31.9°C
```

**水簾出口相對濕度：**
```
RH₂ = 90%（近似飽和）
```

#### 3.1.3 循環水設計
**循環水溫：**
```
Tw = Twb₁ + 1 = 31.3 + 1 = 32.3°C
```

**循環水量計算：**
```
Qw = V × ρ × Cp × (T₁ - T₂) / (4186 × ΔTw)
```
其中：
- V = 通風量 (m³/s)
- ρ = 空氣密度 = 1.15 kg/m³
- Cp = 空氣比熱 = 1005 J/kg·K
- ΔTw = 水溫升 = 3°C

**蒸發水量：**
```
Qevap = V × ρ × (X₂ - X₁) × 3600
```
其中：
- X₁ = 外氣絕對濕度 = 26.5 g/kg
- X₂ = 水簾出口絕對濕度 = 29.8 g/kg

**補給水量：**
```
Qmakeup = Qevap × 1.2（考慮飄水損失）
```

### 3.2 水簾百葉尺寸設計

#### 3.2.1 百葉有效開孔率
```
開孔率 = 75%（波紋紙水簾）
```

#### 3.2.2 百葉表面風速
```
V = Q / (A × 開孔率)
```
其中：
- 建議表面風速 = 1.5-2.0 m/s
- Q = 通風量 (m³/s)
- A = 百葉面積 (m²)

#### 3.2.3 實際百葉設置面積
```
A = Q / (V × 開孔率)
```

### 3.3 水簾阻力計算
```
ΔP = K × (V²/2) × ρ
```
其中：
- K = 阻力係數 = 1.2
- V = 表面風速 (m/s)
- ρ = 空氣密度 = 1.15 kg/m³

## 4. 排氣壁扇設計計算

### 4.1 排氣扇進風條件
- **乾球溫度**：T₃ = T₂ + ΔT（室內溫升）
- **相對濕度**：RH₃ = RH₂ + ΔRH（濕度增加）
- **溫度增量**：ΔT = Qtotal / (V × ρ × Cp)

### 4.2 排氣扇設計計算

#### 4.2.1 風扇風量計算
```
V = max(V必要外氣, V冷卻通風)
```

**必要外氣量：**
```
V必要外氣 = N × v₀
```
其中：
- v₀ = 單位外氣量（依畜種而定）

**冷卻通風量：**
```
V冷卻通風 = Qtotal / (ρ × Cp × ΔT允許)
```
其中：
- ΔT允許 = 6°C（室內允許溫升）

#### 4.2.2 風扇靜壓計算
```
Ps = ΔP水簾 + ΔP管路 + ΔP出口
```

**水簾壓損：**
```
ΔP水簾 = 25 Pa（表面風速2.0 m/s時）
```

**管路壓損：**
```
ΔP管路 = f × (L/D) × (V²/2) × ρ
```
其中：
- f = 摩擦係數 = 0.02
- L = 管路長度 (m)
- D = 當量直徑 (m)

**出口壓損：**
```
ΔP出口 = 0.5 × ρ × V²
```

#### 4.2.3 風扇軸馬力計算
```
BHP = (V × Ps) / (6120 × ηfan)
```
其中：
- V = 風量 (m³/min)
- Ps = 靜壓 (Pa)
- ηfan = 風扇效率 = 0.75

#### 4.2.4 馬達選用馬力
```
Motor HP = BHP / ηmotor × SF
```
其中：
- ηmotor = 馬達效率 = 0.85
- SF = 安全係數 = 1.15

#### 4.2.5 風扇台數計算
```
N = V總風量 / V單台風量
```

### 4.3 排氣扇離風條件
**排氣溫度：**
```
T₄ = T₃ + 1°C（風扇溫升）
```

**排氣濕度：**
```
RH₄ = RH₃（濕度不變）
```

## 5. 系統控制與其他設計考量

### 5.1 自動控制系統
- **溫度感測器**：精度±0.5°C
- **濕度感測器**：精度±3%RH
- **變頻控制**：風扇轉速控制
- **水位控制**：自動補水系統

### 5.2 水質處理
- **過濾系統**：5μm過濾器
- **消毒系統**：UV消毒或氯消毒
- **水質監控**：pH、導電度監控

### 5.3 維護保養
- **水簾更換**：每季檢查，年度更換
- **水質檢測**：每週檢測
- **風扇保養**：每月軸承加油
- **系統清洗**：每月一次

### 5.4 節能設計
- **熱回收**：排氣顯熱回收
- **變頻控制**：依需求調整風量
- **時程控制**：配合畜舍作息

## 6. 設計範例計算

### 6.1 設計條件
- **畜舍類型**：蛋雞舍
- **飼養規模**：10,000隻
- **畜舍尺寸**：60m × 15m × 3m
- **畜舍面積**：900 m²

### 6.2 冷卻負荷計算
**牲畜顯熱負荷：**
```
Qs = 10,000 × 8.5 = 85,000 W
```

**牲畜潛熱負荷：**
```
Ql = 10,000 × 6.5 = 65,000 W
```

**照明負荷：**
```
Qlight = 3 × 900 × 0.85 = 2,295 W
```

**建築傳熱負荷：**
```
Qwall = 0.8 × 450 × 10 × 8 = 28,800 W
Qroof = 0.5 × 900 × 10 × 15 = 67,500 W
Qsolar = 900 × 800 × 0.6 × 0.8 = 345,600 W
```

**總冷卻負荷：**
```
Qtotal = 85,000 + 65,000 + 2,295 + 28,800 + 67,500 + 345,600 = 594,195 W
```

### 6.3 通風量計算
**必要外氣量：**
```
V必要外氣 = 10,000 × 0.5 = 5,000 m³/min
```

**冷卻通風量：**
```
V冷卻通風 = 594,195 / (1.15 × 1005 × 6/60) = 51,673 m³/min
```

**設計風量：**
```
V設計 = max(5,000, 51,673) = 51,673 m³/min = 861 m³/s
```

### 6.4 水簾設計
**水簾面積：**
```
A水簾 = 861 / (2.0 × 0.75) = 574 m²
```

**循環水量：**
```
Qw = 861 × 1.15 × 1005 × (35-31.9) / (4186 × 3) = 247 L/min
```

**蒸發水量：**
```
Qevap = 861 × 1.15 × (29.8-26.5) / 1000 × 3600 = 11,724 L/h
```

### 6.5 風扇設計
**風扇靜壓：**
```
Ps = 25 + 15 + 12 = 52 Pa
```

**風扇軸馬力：**
```
BHP = (51,673 × 52) / (6120 × 0.75) = 586 HP
```

**馬達馬力：**
```
Motor HP = 586 / 0.85 × 1.15 = 793 HP
```

**風扇台數：**
```
N = 51,673 / 8,000 = 6.5 → 7台（單台8,000 m³/min）
```

## 7. 結論

本設計計算書提供了完整的農舍濕簾排風扇系統設計基準，包含各項計算公式及設計參數。設計時應依據實際畜舍條件、當地氣候條件及飼養管理需求進行調整。建議定期檢視系統效能，並依據實際運轉結果進行最佳化調整。
